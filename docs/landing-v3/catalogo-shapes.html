Guia Técnico & Códigos

Como implementar em código.

A máscara usa somente a silhueta do SVG. A cor original do arquivo é ignorada; a propriedade background define a cor final que invade a seção anterior.

1. SVG recomendado

  • Possui viewBox.
  • Contém um shape fechado com fill.
  • A forma alcança as bordas laterais.
  • A área preenchida chega ao topo ou à base.
  • Não depende de imagens externas.

2. Estrutura HTML

<section class="section-dark">
  <div class="content">...</div>
  <div class="shape-divider"></div>
</section>

<section class="section-light">
  <div class="content">...</div>
</section>

3. CSS essencial (Horizontal)

.section-dark {
  position: relative;
  overflow: hidden;
  padding-bottom: 140px;
  background: #080808;
}

.section-light {
  background: #f7f5ef;
}

.shape-divider {
  position: absolute;
  left: 0;
  bottom: -1px;
  width: 100%;
  height: 130px;
  background: #f7f5ef;
  transform: rotate(180deg);

  mask-image: url("./waves.svg");
  mask-size: 100% 100%;
  mask-repeat: no-repeat;

  -webkit-mask-image: url("./waves.svg");
  -webkit-mask-size: 100% 100%;
  -webkit-mask-repeat: no-repeat;
}

4. CSS essencial (Vertical)

.vertical-divider {
  position: absolute;
  top: 0;
  bottom: 0;
  width: 170px;
  background: #f7f5ef;

  /* Mesmo path do waves.svg, salvo com viewBox vertical. */
  mask-image: url("./waves-vertical.svg");
  mask-size: 100% 100%;
  mask-repeat: no-repeat;
}

/* A próxima seção entra pela direita */
.vertical-divider.from-right {
  left: 50%;
}

/* A seção escura entra pela esquerda */
.vertical-divider.from-left {
  right: 50%;
  background: #080808;
}

5. Ajustes rápidos

  • Cor: altere o background do divisor.
  • Profundidade: altere o height.
  • Orientação: use rotate(180deg).
  • Espelhamento: use scaleX(-1).
  • Mobile: reduza a altura com media query.
@media (max-width: 800px) {
  .shape-divider { height: 74px; }
}

6. Efeito Paralaxe de Fundo

É possível combinar máscaras com efeitos de paralaxe na imagem de fundo. A máscara atua como uma "janela de corte" fixa na seção, enquanto a imagem de fundo se move por trás da curva do SVG quando o usuário rola a página, criando profundidade 3D. 

.section-below {
  /* ... estilos da máscara ... */
  background-image: url("./background.jpg");
  background-size: cover;
  background-position: center;
  background-attachment: fixed; /* Parallax CSS */
}

*Nota: Em dispositivos móveis (como iOS), o background-attachment: fixed pode ser desabilitado automaticamente pelo navegador por questões de desempenho.

7. Validação de QA

  1. Confirme que não existe uma faixa reta entre as seções.
  2. Teste desktop e celular.
  3. Verifique se não apareceu rolagem horizontal.
  4. Confirme que o SVG continua nítido em telas grandes.
  5. Revise a licença do gerador ou arquivo utilizado.

8. Quando não usar máscara

Use SVG inline ou como imagem quando precisar preservar gradientes, várias cores, contornos ou animações internas. A máscara é melhor para shapes sólidos cuja cor deve ser controlada pelo CSS.

Prompt pronto para entregar a qualquer agente

Substitua os campos entre colchetes e envie junto com o SVG escolhido. 

Use o arquivo SVG [CAMINHO_DO_SVG] como separador responsivo entre
a seção [SEÇÃO_ANTERIOR] e a seção [PRÓXIMA_SEÇÃO].

Requisitos:
- Não altere o conteúdo ou layout das seções.
- Use o SVG como CSS mask para controlar a cor pelo CSS.
- A cor do divisor deve ser igual ao fundo da próxima seção: [COR].
- Posicione o divisor no final da seção anterior.
- Ajuste a orientação com rotate/scale quando necessário.
- Use altura aproximada de [130px] no desktop e [74px] no mobile.
- Para orientação vertical, use rotate(90deg) or rotate(-90deg).
- No mobile, transforme divisores verticais em seções empilhadas.
- Evite faixa reta, espaços, sobreposição de conteúdo e scroll horizontal.
- Valide visualmente em desktop e mobile.
- Preserve acessibilidade usando aria-hidden="true" no divisor decorativo.

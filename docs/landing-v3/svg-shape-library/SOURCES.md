# SVG Shape Library

## Downloaded collection

- Source: https://github.com/andraswebcode/shape-dividers
- Folder: `cc0-shape-dividers/`
- License: CC0-1.0
- Use: horizontal dividers, patterns, curves, waves, triangles, clouds and drops.

## Custom collection

- Folder: `custom/`
- Created specifically for this guide.
- Use: blobs, page-edge framing, corner treatment and decorative highlights.

## Recommended implementation

- Use solid shapes as CSS masks when color must be controlled by CSS.
- Use SVG inline when the file has multiple colors, strokes, gradients or internal animation.
- Preserve `viewBox` and use `preserveAspectRatio="none"` only when intentional stretching is acceptable.
